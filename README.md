# Product Inventory & Analytics Dashboard

**JavaScript Curriculum — Week 4 Mini Project**

## Project Overview
This beginner-friendly project is an interactive product inventory dashboard built with HTML, CSS, and JavaScript. It demonstrates JavaScript variables, data types, conditions, loops, functions, arrays, objects, and array methods.

## Features
- Add a product using `prompt()`.
- Convert the entered price to a number and validate it.
- Categorize products as **Budget**, **Standard**, or **Premium**.
- Display products and their categories in a dashboard.
- Calculate the total inventory value.
- Filter products priced under $200.
- Generate a formatted report using `map()`.
- Print a detailed report to the browser's Developer Console.
- Reset the inventory to the original sample products.

## Sample Products
| Product | Price | Category |
|---|---:|---|
| Laptop | $800 | Premium |
| Mouse | $25 | Budget |
| Monitor | $150 | Standard |

With these sample products, the total inventory value is **$975**. Products under $200 are **Mouse** and **Monitor**.

## How to Run
1. Download `product_inventory_dashboard.html`.
2. Open the downloaded file in a modern web browser such as Google Chrome.
3. Click **Add Product (prompt)** to add a product.
4. Enter a product name and a positive price.
5. Click **Show Console Report** to view the report. Open Developer Tools → Console for detailed output.
6. Click **Reset Inventory** to restore the original sample products.

No server or additional software installation is required.

## JavaScript Concepts Demonstrated
- Variables: `const` and `let`
- Data types and explicit conversion with `Number()`
- Conditional logic: `if...else` and `switch`
- Loops: `for`, `while`, and `do...while`
- Loop control: `break` and `continue`
- Functions, parameters, and default values
- Arrow functions and local scope
- Arrays of objects
- Array methods: `forEach()`, `filter()`, and `map()`
- DOM updates and event listeners
- Input validation and basic error handling

## Category Rules
- **Budget:** price below $50
- **Standard:** price from $50 up to (but not including) $200
- **Premium:** price of $200 or more
